# QazaqAI v2 — Инструкция по запуску 🚀

## Что это такое?

**QazaqAI** — веб-приложение для изучения казахского языка с помощью ИИ (Gemini от Google).
Всё работает прямо в браузере, никакой установки серверов не нужно!

---

## 📁 Структура проекта

```
qazaqai/
├── index.html       ← главная страница (открывай её!)
├── css/
│   └── main.css     ← стили
└── js/
    ├── data.js      ← словарь, грамматика, квизы
    └── app.js       ← логика приложения
```

## 🖥️ КАК ЗАПУСТИТЬ (3 способа, от простого к правильному)

### Способ 1: Просто открыть файл (самый простой)
1. Найди папку `qazaqai` у себя на компьютере
2. Дважды кликни на файл `index.html`
3. Откроется в браузере (Chrome, Firefox, Edge — все подойдут)

⚠️ **Проблема этого способа:** Реальный Gemini AI **не будет работать** из-за ограничений безопасности браузера (CORS). Приложение запустится, но чат будет использовать заготовленные ответы.

---

### Способ 2: Через VS Code (рекомендуется для новичков)
1. Скачай **VS Code** бесплатно: https://code.visualstudio.com
2. Установи расширение **"Live Server"**:
   - Открой VS Code
   - Нажми Ctrl+Shift+X (Extensions)
   - Найди "Live Server" от Ritwick Dey
   - Нажми Install
3. Открой папку `qazaqai` в VS Code (File → Open Folder)
4. Правой кнопкой кликни на `index.html`
5. Выбери **"Open with Live Server"**
6. Браузер откроется автоматически на `http://127.0.0.1:5500`
7. ✅ Теперь Gemini AI работает полностью!

---

### Способ 3: Через Python (если он установлен)
1. Открой командную строку (cmd на Windows / Terminal на Mac)
2. Перейди в папку проекта:
   ```
   cd путь/к/папке/qazaqai
   ```
3. Запусти сервер:
   ```
   python -m http.server 8000
   ```
4. Открой браузер и перейди на: http://localhost:8000
5. ✅ Готово!

## 🤖 Подключение реального Gemini AI

Чтобы бот отвечал по-настоящему умно:

1. Зайди на https://aistudio.google.com/app/apikey
2. Войди через Google-аккаунт (если нет — создай, бесплатно)
3. Нажми **"Create API key"**
4. Скопируй ключ (выглядит как `AIzaSy...`)
5. В приложении:
   - Войди в аккаунт
   - Перейди в **Профиль** (иконка 👤)
   - Прокрути вниз до раздела **"Gemini API-ключ"**
   - Вставь ключ и нажми **"Сохранить ключ"**
6. ✅ Теперь Gemini AI отвечает по-настоящему!

## 👤 Регистрация и вход

При первом запуске:
1. Нажми **"Регистрация"**
2. Введи имя, логин (только латиница/цифры/_), пароль (мин. 6 символов)
3. Выбери уровень казахского
4. Нажми **"Создать аккаунт"**

Для быстрого теста: логин **demo**, пароль **demo123**

## ❓ Часто задаваемые вопросы

**Q: Почему бот не отвечает умно?**
A: Нужен Gemini API-ключ. Без него — заготовленные ответы. Смотри раздел "Подключение AI".

**Q: Данные сохраняются?**
A: Да, всё хранится в браузере (localStorage). При очистке кэша данные сотрутся.

**Q: Работает на телефоне?**
A: Да, откройте сайт через Live Server с ПК и зайдите с телефона в той же сети.

**Q: Нужен интернет?**
A: Для загрузки шрифтов и Gemini AI — да. Основной функционал (кроме AI) работает офлайн.

## 🆘 Если что-то не работает

1. Обнови страницу (F5)
2. Попробуй другой браузер (Chrome рекомендуется)
3. Используй Live Server вместо прямого открытия файла
4. Проверь консоль браузера (F12 → Console) — там будут ошибки
